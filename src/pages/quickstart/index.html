Quickstart

From install to first push in minutes

Two installs, one click. Blender 4.0 to 5.x and the Figma desktop app.

Get the files. The free download isn't published yet. After checkout, paid plans send download links by email.

1. Install the Blender add-on

  1. Download figment_bridge_blender.zip and don't unzip it.
  2. In Blender: Edit › Preferences › Add-ons, open the dropdown at the top right, choose Install from Disk… and pick the zip.
  3. Enable Figment Bridge. In the 3D Viewport press N and open the Figment tab. The header shows Listening on :8765.

The bridge only listens on 127.0.0.1, your own computer. If the port is taken, pick another between 8765 and 8769 in the add-on preferences.

2. Install the Figma plugin

  1. Download figment_bridge_figma.zip and unzip it anywhere.
  2. In the Figma desktop app: Plugins › Development › Import plugin from manifest… and choose manifest.json.
  3. Run Plugins › Development › Figment Bridge. The status pill turns green when Blender is connected.

3. Push

  1. Select one or more frames, or any layers.
  2. Choose your options: Update in place keeps your Blender work, Replace rebuilds. Text can come in editable, as outlines or as an image.
  3. Click Push to Blender, or press Ctrl + Enter.

Live Sync (Premium): select the frames and switch Live Sync on. Every edit is applied in place, so keyframes, nudges, modifiers and materials stay intact.

No connection? Save a .zip or scene.json from the plugin, then use Figment › Import in Blender.

4. Tips

  • Animate freely. Figma placement lives in the delta transform channels, so your location, rotation and scale keys survive every update.
  • Add [z+2] or [z-1] to a Figma layer name to lift or lower it and its contents.
  • Install your Figma fonts on the same machine for editable text with the right typeface. Missing fonts are listed in the plugin and in Blender.

Troubleshooting

  • "Blender offline": check the add-on is enabled and the panel says Listening. Click the status pill to re-scan ports 8765 to 8769.
  • "Update add-on": the add-on is older than the plugin. Install the newest zip.
  • Port in use: change the port in the add-on preferences and pick the same one in the plugin's More options.

Tested on Blender 5.0 for Windows. Other versions and systems haven't been tested yet.
